本地生词本构建流程

项目概述

使用本地 Ollama 模型 + Python 脚本 + 静态 HTML 页面，搭建一个离线可用的英语生词本。整个流程不需要联网（除首次拉取模型和词库外），所有数据保存在本地。

项目文件结构

核心脚本说明

add-word.py

负责以下工作：

  1. 查询 WordNet：获取单词的释义、同义词、反义词和例句，作为 AI 生成的参考依据。
  2. 调用 Ollama：将 WordNet 数据 + 提示词发送给本地模型，生成结构化的词典条目（中文意思、用法、其他形式、例句）。
  3. 追加写入 Markdown：将生成的词条内容追加到 生单词.md 中，每个单词作为一个独立的 word-item 块，方便后续检索和展示。

add-word.sh

Shell 封装脚本，负责：

  1. 校验是否传入了单词参数。
  2. 获取脚本所在目录，确保能找到 add-word.py。
  3. 遍历所有传入的单词，逐个调用 add-word.py 处理。

展示页面说明

生单词.md

Hexo 源文件，由 Python 脚本追加写入。每个单词是一个 <div class="word-item"> 块，包含：

  1. 单词标题：### 单词名，作为词条入口。
  2. 中文意思：逐条列出义项，带词性标注。
  3. 用法：固定搭配 + 常见用法。
  4. 其他形式：派生词、词形变化、反义词。
  5. 例句：每条配 <button class="speak-btn">，前端通过 speechSynthesis API 朗读。

Hexo 部署后会自动将该文件渲染为 HTML 页面，配合前端 JS/CSS 实现 A-Z 索引、搜索过滤、展开收起等功能。

注意事项

  1. Ollama 服务必须先启动，否则脚本无法调用模型。
  2. 首次运行会比较慢，因为模型需要加载到内存中；后续调用会快很多。
