单词笔记

used to / didn’t use to

对比

形式 结构 含义 例句
肯定 used to + 动词原形 过去常常……；过去是……（现在不是） I used to play basketball.
否定 didn’t use to + 动词原形 过去不常……；过去不是…… I didn’t use to like coffee.
正式否定 used not to + 动词原形 过去不常…… She used not to drink coffee.
疑问 Did + 主语 + use to + 动词原形? 过去常常……吗？ Did you use to live here?
易混 be used to + 名词/doing 习惯于…… I am used to getting up early.
易混 get used to + 名词/doing 逐渐习惯…… He is getting used to his new job.
易混 be used to do 被用来做…… Wood is used to make paper.

意思

  • used to + 动词原形：过去常常做某事；过去是某种状态（现在不再这样）
  • didn’t use to + 动词原形：过去不常做某事；过去不是某种状态
  • be used to + 名词/动名词：习惯于……
  • get used to + 名词/动名词：逐渐习惯于……
  • be used to do：被用来做……

用法

  • used to 只谈过去，不能表示现在的习惯。
  • 否定和疑问里已经有 did，所以后面用 use，不用 used。
  • 标准书面：didn’t use to + 动词原形。
  • 标准疑问：Did you use to…?
  • used to 常读 /ˈjuːstə/；didn’t use to 常读 /ˈdɪdənt ˈjuːstə/。
  • 不要和 be used to doing（习惯于做某事）混淆。

其他形式

  • use（v. 使用）
  • used（adj. 用过的；旧的）
  • be used to（习惯于）
  • get used to（逐渐习惯）
  • be used to do（被用来做）

词源

  • use 源自古法语 user，拉丁语 uti（使用）→ used to 由“过去惯常”的用法演变而来。

例句

  • （我过去每天走路上学）
  • （我过去不喜欢蔬菜，但现在喜欢了）
  • （你过去弹钢琴吗？）
  • （她过去不喝咖啡）
  • （我习惯于早起）
  • （他正逐渐习惯新工作）
  • （木材被用来造纸）
