十一、Windows 本机 IDE 安装

IntelliJ IDEA Community（写 Java 用）

下载
  1. 打开浏览器，访问：https://www.jetbrains.com/idea/download/
  2. 找到 Community 那一栏（免费的，左边那个）
  3. 点击橙色的 Download 按钮

[!warning] 注意
不要下载 Ultimate（收费版），选 Community（免费版）就够用了。

安装步骤
  1. 双击下载好的 .exe 安装包
  2. 一路点 Next，大部分选项保持默认
  3. 在 Installation Options 页面，勾选以下选项：
    • ✅ Create Desktop Shortcut（创建桌面快捷方式）
    • ✅ Add “Open Folder as Project”（右键菜单可以直接用 IDEA 打开项目）
    • ✅ Add launchers dir to the PATH（添加到系统 PATH）
  4. 在 Choose Boot Environment 页面，选择 JetBrains Runtime（默认选项）
  5. 点击 Install，等待安装完成
  6. 点击 Finish，勾选 Run IntelliJ IDEA 启动
首次启动配置
  1. 启动后选择 Do not import settings（不导入旧设置）
  2. 选择主题：推荐选 Darcula（深色主题，护眼）
  3. 点击 Next，到 Plugins 页面，保持默认，点 Start Using IntelliJ IDEA
连接 WSL
  1. 打开 IDEA，点击菜单 File → Open
  2. 在路径栏中输入 WSL 项目路径，格式为：\\wsl$\Ubuntu\home\你的用户名\项目目录
  3. 例如：\\wsl$\Ubuntu\home\zzc\java-test
  4. 点击 OK，IDEA 会打开 WSL 里的目录

VS Code（写 Python / 前端 / 通用）

下载
  1. 打开浏览器，访问：https://code.visualstudio.com/
  2. 点击蓝色的 Download for Windows 按钮
安装步骤
  1. 双击下载好的安装包
  2. 勾选 我接受协议，点 下一步
  3. 选择安装位置：保持默认，点 下一步
  4. 选择开始菜单文件夹：保持默认，点 下一步
  5. 选择附加任务（重要）：
    • ✅ 将”通过 Code 打开”操作添加到 Windows 资源管理器文件上下文菜单
    • ✅ 将”通过 Code 打开”操作添加到 Windows 资源管理器目录上下文菜单
    • ✅ 将 Code 注册为受支持的文件类型的编辑器
    • ✅ 添加到 PATH（默认已勾选）
  6. 点击 安装，等待完成
安装 WSL 扩展（关键）
  1. 打开 VS Code
  2. 按 Ctrl + Shift + X 打开扩展面板
  3. 搜索：WSL
  4. 找到第一个结果：WSL（发布者是 Microsoft）
  5. 点击 Install
