使用Deepseek Harness 搭建 Hexo 轻量级博客

Created2026-09-11|Updated2026-09-11
|Post Views:

使用 DSH 去搭建 Hexo 轻量级博客，并且将它挂在 Github 上面

第一步：启动 DSH 并新建工作区

打开 DSH Web 界面，在左侧工作区的位置新建一个工作区

工作区自己定义，我这里定义的是中文，日记本，因为不是常用到，所以用了中文。

工作区建立完成后，给智能体发送信息：

  • 自动检查并提示安装 Node.js 和 Git（如果未安装）,Git全局安装。
  • 自动全局安装 Hexo CLI。
  • 在当前目录下创建一个名为 my-hexo-blog 的文件夹，并在里面初始化 Hexo 博客。
  • 自动安装 hexo-deployer-git 插件。

    我这里配置完成之前也是需要与 DSH 进行沟通，它问我要 Git 全局的用户信息，只需要按它提示的内容去回答即可。

第二步：根据 DSH 完成任务后的提醒反馈处理

我的反馈是因为我没有提前在 Github 上创建项目，所以它在部署完成后进行测试的时候，提示了 hexo d 推送失败。

这里根据它的反馈，我去 Github 上面完成操作后，直接告诉它，我解决了，进行下一步。

这里是获取 repo 的 URL 地址，直接复制，可以自己手动去改，也可以把地址发给它，让它来改。

继续操作之后的时候会提示去添加密钥，自己注意 DSH 的提示，添加密钥是去 Github 设置里面添加一个 SSH and GPG Key 里面。

继续根据它的反馈去做，我这里贴的是我在操作时候的反馈，自己根据情况来定。

根据它的反馈，我发送的命令是：“进行jekyll处理，在新增一个脚本，当我每次需要写新文章的时候，操作一下脚本，询问我是创建新文档还是同步”。
因为我比较懒，所以更喜欢按数字去回复，方便快捷。

基本上到这里就结束了，如果有其他的问题，我这边建议直接打开 Deepseek 网页免费版、 千问网页免费版、 豆包等等AI 免费版，去问它们即可。

我根据我的需求让它重新给我更新了 Butterfly 主题，因为自己有域名，所以我打算使用自己的域名去挂，而不是 Github 免费的域名，当然根据个人需求。

在使用自己域名去解析的时候出现了以下问题：

  • 页面存在文字，没有样式

我开始以为是同步的时候出了问题，检查了配置文件，并没有什么问题，也询问了 AI 关于配置文件有没有问题，最终的检查结果和执行方案是 AI 这边加了一行在 config.butterfly.yml 文件中，但是没有用。

后续检查发现是 css 和 js 的文件没有被获取到，简单排查后发现修改 config 文件中的 URL 就可以了，主要是路径问题

域名解析选择 CNAME ，记录值就是 用户名.github.io
如果不用域名，更改主题后会不会出现这种问题我不知道，但是如果出现了，可以尝试在 URL 这里进行简单的尝试。
